FITTERFIELD™
Stripe Connect V2 demo

Connect payments to FitterField.

Onboard a merchant, check their live Stripe status, create products, and give their customers a simple hosted Checkout storefront.

Demo note: this page uses a Stripe account ID in the URL. In production, use your own merchant/user ID and resolve it to the Stripe account server-side.

1. Merchant onboarding

Create a V2 connected account, then send the merchant through Stripe Account Link onboarding.

No account loaded.

2. Merchant subscription

Charge the connected account a recurring FitterField service fee using the V2 customer_account model.

The demo subscription Price is configured server-side. Replace CONNECT_SUBSCRIPTION_PRICE_ID in Render if you want a different plan.

3. Create products for this merchant

Create or load a connected account first.

4. Customer storefront

Customers buy products from the connected merchant using Stripe-hosted Checkout. Direct charges include a sample FitterField application fee.

Webhook setup

Normal Billing events go to /webhooks/stripe. V2 thin account events go to /webhooks/stripe-v2. The server retrieves the full V2 event and then the current Account state after requirements/capability changes.

Local Stripe CLI:
stripe listen --thin-events 'v2.core.account[requirements].updated,v2.core.account[configuration.merchant].capability_status_updated,v2.core.account[configuration.customer].capability_status_updated,v2.core.account[configuration.recipient].capability_status_updated' --forward-thin-to http://localhost:10000/webhooks/stripe-v2
